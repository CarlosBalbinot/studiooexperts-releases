# Studioo Experts — instaladores

Instaladores do aplicativo Windows do Studioo Experts. Este repositório contém **somente os
instaladores** (o código é privado) e é de onde o app baixa as atualizações automáticas.

**Baixar:** abra [Releases](https://github.com/CarlosBalbinot/studiooexperts-releases/releases/latest)
e baixe o arquivo `Studioo-Experts-Setup-X.Y.Z.exe` da versão mais recente.

Baixe somente deste endereço.
